# Solar System Exploration 3 (SSE3)
Welcome to Solar System Exploration 3 (shortly SSE3).
This is an official open-source page for SSE3.
The game is currently in development. Many functions **do not** work or have not been added yet.
## Сontrols
WASDQE - rocket orientation
<> - time multiplier (the higher it is, the faster the time is inside the game)
RMB hold and drag - move camera around the rocket
Mouse scroll wheel - zoom out or in from the rocket
